# 逐語抽出の指示文（2026年7月24日に使ったもの）

方法論文 *What Breaks in a Citation* v1.2 §8-2 が「解釈を禁じる指示の下での逐語抽出」と呼ぶ作業で、4本の作業スレッドの最初の発話として使った指示文です。下の枠内は、その発話のうち抽出対象の一覧の前までを、空欄も含めてそのまま写したものです。直したところはありません。

4本では、【抽出対象】の欄は空欄の型のまま残り、実際の対象は【報告形式】の表の後ろに番号付きで足されていました。4本の対象は `examples/extraction_2026-07-24/` にあります。

改訂版は `extraction_prompt_v2_ja.md` です。

```text
以下のPDFから、指定した条項を「逐語」で抽出してください。
【厳守事項】
・条文の逐語引用のみ。要約・言い換え・解釈を一切加えない
・改正履歴の脚注があれば、それも逐語で写す（重要な情報が含まれます）
・条項が見つからない場合は「見つからない」と報告する。推測で補わない
・重要性の判断、他条項との関係の説明は不要
【PDFの扱い】
・まずページ数とテキスト層の有無を確認（pdfinfo / pdffonts）
・テキスト層がなければOCR（tesseract）
・該当条項のページ番号を必ず特定する
【抽出対象】
1. ［条項番号］ ―［日本語での説明］
2. ［条項番号］ ―［日本語での説明］
【報告形式】
下記の表を埋めて返してください。
| 項目 | 内容 |
|---|---|
| 資料の正式名称 | |
| 発行主体 | |
| 版・最終改正日 | |
| 総ページ数 | |
| 該当条項のページ | |
| 逐語引用 | （原文のまま） |
| 改正履歴の脚注 | （あれば原文のまま） |
| 見つからなかった項目 | |
```
