# 逐語抽出の指示文 改訂版（v2、キットv1.9）

2026年7月24日の指示文（`extraction_prompt_2026-07-24_ja.md`）を、4本の作業スレッドで起きたことに合わせて直したものです。2026年7月の4本では、逐語・頁・「見つからない」は守られましたが、原文が尽きた箇所に、資料の外の知識や資料どうしの関係の判断が説明として入りました（Hypothetical Technical Blog #27）。

改訂の方針は、資料の外の知識を禁じることではなく、別の欄に隔離して出所を付けさせることです。行き先の見当は役に立つことがあります。困るのは、それが抽出の報告の中に、抽出と同じ顔で入ることです。

変えたところ：

- 「見つからない」を「このPDFにはない」とし、存在しないとは言わせない。検索の記録（何を検索し、何件あり、どこまで見たか）を必須にする。
- 頁はPDFの頁と印字の頁を両方書かせる。
- 資料に書かれていないこと（どの告示が入れたか、別名、法的な評価など）は【資料の外から来たもの】の欄にだけ書かせ、出所を付けさせる。
- 2つ目の資料が来たら別の報告にし、資料どうしを比べさせない。
- 指示どおりにできないとき（著作権など）は、どの行に従えないかと理由を【指示から外れたこと】に書かせる。

機械で読む形は `schema/extraction.schema.json`、検査は `tools/extractcheck.py` です。

```text
以下のPDFから、指定した条項を「逐語」で抽出してください。
【厳守事項】
・条文の逐語引用のみ。要約・言い換え・解釈を一切加えない
・改正履歴の脚注があれば、それも逐語で写す（重要な情報が含まれます）
・条項が見つからない場合は「このPDFにはない」と報告する。存在しないとは書かない。推測で補わない
・見つからない項目には、検索の記録を付ける（検索した語、ヒット数、確認した範囲）
・重要性の判断、他条項・他資料との関係の説明は不要
・資料に書かれていないこと（どの告示が入れたか、正式名称、別の版、法的な評価など）は、逐語・頁・見つからなかった項目の欄に書かない。書くなら【資料の外から来たもの】の欄にだけ書き、出所（記憶／別の資料の名前）を付ける
・別の資料が追加されたら、その資料だけの報告を別に作る。資料どうしを比べない
・指示のどれかに従えないときは、どの行に従えないかと理由を【指示から外れたこと】に書く
【PDFの扱い】
・まずページ数とテキスト層の有無を確認（pdfinfo / pdffonts）
・テキスト層がなければOCR（tesseract）
・該当条項のページを、PDFの頁と印字の頁の両方で特定する
【抽出対象】
1. ［条項番号］
2. ［条項番号］
【報告形式】
下記の表を埋めて返してください。
| 項目 | 内容 |
|---|---|
| 資料の正式名称 | （資料に書かれているとおり） |
| 発行主体 | （資料に書かれているとおり。なければ「記載なし」） |
| 版・最終改正日 | （資料に書かれているとおり） |
| 総ページ数 | （PDFの頁数／印字の最終頁） |
| 該当条項のページ | （PDF頁／印字頁） |
| 逐語引用 | （原文のまま） |
| 改正履歴の脚注 | （あれば原文のまま） |
| 見つからなかった項目 | （「このPDFにはない」と検索の記録） |
| 資料の外から来たもの | （あれば。1件ごとに出所を付ける） |
| 指示から外れたこと | （あれば。どの行か、理由） |
```

抽出対象には、条項番号だけを書くことを勧めます。2026年7月の4本では、対象に「監査証跡・編集ログ・無効化不可の要件と、適用開始事業年度」のような中身の説明が付いていました。説明は依頼した側の予想で、抽出係にとっては確かめる対象です。説明を付けるなら、別の行に「予想（確かめること）」として書いてください。
